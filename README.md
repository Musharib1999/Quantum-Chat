# OptiOS Next.js Frontend Specification

The **OptiOS Next.js Frontend** is a responsive, modern web application built on **Next.js (App Router)** and **TypeScript**. It connects users to quantum optimization compilers and assistant workflows.

---

## 1. Tech Stack & Dependencies

* **Framework:** Next.js (React 18) with App Router.
* **Language:** TypeScript.
* **Styling:** Custom CSS modules with curated modern dark-mode aesthetics.
* **Key Packages:**
  * `@monaco-editor/react`: Code editor for rendered optimization scripts.
  * `lucide-react`: Curated modern interface icons.
  * `bcryptjs`: Password hashing on admin/auth routes.
  * `mongoose`: Client-side models for MongoDB cache/auth checks.

---

## 3. Core Functional Modules

### A. Real-Time Pipeline Streamer (`useQuantumChat.ts`)
Connects to `/api/chat/stream`, which proxies FastAPI's SSE stream. The hook reads streamed chunks dynamically and updates the `workflowSteps` UI state (NLP Parser ➔ Feasibility ➔ Routing ➔ Code Generation ➔ Sandbox Verification ➔ Interpretation) in real-time.

### B. Latency Mitigation & Caching (`actions/chat.ts`)
* **Exact Hash Matching:** Hashes user prompts using SHA-256. Checks MongoDB collection `solvedproblems` for matching solves to return cached code block results in `< 100ms`.
* **Keyword Overlap Semantic Cache:** If exact match misses, checks keyword overlap intersection. If similarity is **>= 88%**, serves the cached formulation, bypassing long LLM generation paths.

### C. LaTeX Math Formulation Renderer (`MarkdownRenderer.tsx`)
Formats LaTeX markup equations (e.g. `\( \min \sum c_i x_i \)` and `\[ \text{subject to } Ax \le b \]`) generated by the compiler agent into human-readable math layouts.

### D. Security & Admin Dashboard (`admin/dashboard/page.tsx`)
* Protected route guards inside `middleware.ts`.
* Configures 7 essential tabs: **User Management**, **Guardrail Management**, **Prompt Settings**, **Vector Data RAG**, **System Log Audits**, and **Hardware Node Status Checks**.
